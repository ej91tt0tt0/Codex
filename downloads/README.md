# よりそい — AI検索・自動情報収集 v0.8.0

[Windows更新版ZIP](https://github.com/ej91tt0tt0/Codex/raw/refs/heads/main/downloads/yorisoi-windows-research.zip)

よりそいが会話の内容から必要な情報を判断し、Web検索で確認して答える機能を追加しました。画面の出典リンクから根拠を確認できます。外部の検索ページに移らず、アプリ内で調べものができます。

## 使い方

- 「今日の碧南市の天気を調べて」
- 「名鉄三河線の運行情報を確認して」
- 「最近のゲームのニュースを調べて」

AIが検索の必要性を判断します。雑談や挨拶では検索を使わないよう指示しています。メニュー → ナビ・調べものの入力欄からも、AIに調べものを依頼できます。回答の下と会話履歴に出典・調査日時を表示します。検索で確認できない情報を、現在の事実として断定しないようにしています。

## 1時間ごとのAI調査

既存の気象庁予報・ニュースRSS収集に加え、登録テーマをAIが1時間ごとに調べ、出典付きのダイジェストを保存します。初期テーマは天気、交通情報、政治、ニュース、スポーツ、ゲーム、エンタメ。地域テーマは碧南市、名鉄三河線、知多半島道路、国道23号、愛知県交通情報などです。

1回につき検索ツールの呼び出しを最大2回に制限し、確認した範囲と未確認の分野を示します。全テーマを毎回網羅できるとは限りません。検索で運休や渋滞が見つからなくても、異常なしという意味ではありません。運転・乗車前には公式の最新情報も確認してください。

メニュー → 天気・ニュース・交通 → AIの情報収集で、レポート、出典、失敗状況を確認できます。「AIで今すぐ調査」も使えます。

- 「設定変更、Web検索を止めて」：会話の検索と定時のAI調査を停止。
- 「設定変更、AIの自動収集を止めて」：定時のAI調査だけ停止。
- 再開は「止めて」を「再開して」に変更。

PC・サーバー・インターネットが動いている間のみ実行します。既定で有効で、初回は起動後約1分以内、その後は前回試行から1時間ごと。失敗しても1時間以内に自動再試行しません。自動収集全体のスイッチがオフならAIの定時調査も停止します。要約の自動読み上げや、他のサービスへの通知・投稿は行いません。

## 更新手順

1. 旧版を黒い画面でCtrl+Cを押して終了。
2. ZIPをすべて展開し、`yorisoi` の中身を既存の `yorisoi` へ上書き。既存の `.data` は残してください。
3. `start_windows.bat` を開き、有効なOpenAI APIキーを入力してEnter。
4. 音声会話を開始するか、メニューの「AIで今すぐ調査」で動作を確認。

Python 3.12以上、ChromeまたはEdgeを推奨。会話、体調、記憶、設定は引き継ぎます。ZIPには新しい `research.py` が含まれます。従来のダウンロード名も同じ最新版へ更新しています。

## AI・料金・情報の扱い

AIはOpenAI APIを使います。PC内で推論するAIモデルを同梱するものではありません。会話にはResponses API、検索にはOpenAIのWeb検索を使います。既存のOpenAI APIキー以外に検索用APIキーは不要ですが、利用可能なモデルと利用枠が必要です。会話・検索・音声は従量課金で、定時調査を有効にすると定期的なAPI料金が発生します。

定時のAI調査には、登録テーマ・地域テーマと市区町村までの地域だけを渡し、会話・記憶・体調を渡しません。会話AIには従来どおり会話、記憶、最近の体調、地域、天気、ニュース、会話ルールを送信します。検索語へ個人の氏名・詳細な住所・健康記録を入れないようAIに指示します。

調査結果と出典はPC内SQLiteへ直近100件保存します。画面で取得するのは直近20件、定時レポート欄にはそのうち直近5件を表示。データ管理から削除できます。ZIPにAPIキーや実際の履歴・体調・調査結果は含めません。

## 既存の機能

青年らしい音声、句読点まで読んで交代する方式、発声中の音声認識、追加発言の保持、実測音量の円形表示、音声の設定変更、改善リクエスト保存、Googleマップの車経路連携も含みます。WindowsのGoogleマップは経路プレビューです。実際の運転ナビは対応スマホのGoogleマップで使用してください。

外部記事をアプリ操作の指示として実行しません。Googleマップの起動は利用者の明示依頼からだけ行います。AIが自分でコードを書き換えたり、任意のOS操作を実行したりする機能は追加していません。

## 検証状況

このクラウド環境ではAPI認証が通らず、実APIでのWeb検索の確認は未完了です。PCで入力するキーの有効性とは別です。模擬API応答を使って、検索と出典の処理、失敗表示、定時実行条件、停止設定、画面操作、データ保持を検証しています。
