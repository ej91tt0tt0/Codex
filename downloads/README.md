# よりそい — 控えめな声かけと自然な会話の交代 v0.10.0

[Windows更新版ZIP](https://github.com/ej91tt0tt0/Codex/raw/refs/heads/main/downloads/yorisoi-windows-flow.zip)

## 今回の変更

自動の声かけは、既定で10分以上の沈黙後に1回だけに減らしました。返事がなければ休止し、マイクの待ち受けを続けます。登録テーマを使った自動の話題提案は既定でオフです。質問への回答では、今の話と関係する資料だけを使い、無関係なニュースを付け足さないよう指示しています。

「、」「。」ごとの読み上げ分割をやめ、短い返答は結論と理由まで一つのまとまりとして話します。長い説明は意味が完結する段落で分け、理由・例示などの導入を前の説明とつなぎます。追加の発言や訂正は保持し、今のまとまりを話し終えてから返答します。話し始めた音を検知しただけでは読み上げを打ち切りません。

「話す／会話を渡す」ボタンも、現在のまとまりを話し終えて交代します。すぐに止めたい場合は「停止」か上部のマイクボタンを使ってください。音声認識後の「マイクを止めて」も従来どおり即時停止します。

意味のまとまりはAIが生成する段落と接続表現で扱います。実音声の抑揚を分析する機能ではありません。極端に長い単一段落だけは、音声APIの文字数制限に合わせて分割します。

## 設定と更新

1. 旧版を黒い画面でCtrl+Cを押して終了。
2. ZIPをすべて展開し、`yorisoi` の中身を既存の `yorisoi` へ上書き。既存の `.data` は残してください。
3. `start_windows.bat` を起動してAPIキーを入力。

更新時に一度だけ、10分未満の声かけ間隔を10分へ変更し、登録テーマの話題提案をオフにします。以前から声かけ自体をオフにしていた場合はオフを維持します。会話・体調・記憶・常時待ち受け・情報収集の設定は保持します。更新後に編集した設定は、次回起動でも上書きしません。

メニュー → 声かけ・音声の設定から、間隔や「登録テーマを使った話題提案」を変更できます。

- 「設定変更、声かけを減らして」：10分間隔へ変更。
- 「設定変更、テーマの話題提案を減らして」：テーマ提案をオフ。
- 「設定変更、声かけを止めて」：自動の声かけ自体をオフ。

テーマのニュース・天気・交通情報などの収集は、従来の1時間ごとのままです。必要なときに声で質問できます。自動声かけは会話画面の表示中だけ動作し、次にユーザーが発言すると休止を解除します。

## 継続する機能・制約

常時待ち受け、青年らしい音声、音量に反応する円形表示、音声設定、改善リクエスト、Googleマップの車経路、AIのWeb検索と定時調査も含みます。従来のダウンロード名も同じ最新版です。

Python 3.12以上とChrome/Edgeを推奨。初回は音声会話を開始してマイクを許可してください。許可済みの高精度認識では、次回から自動待ち受けが可能です。周囲の人やテレビの声にも反応し得ます。ブラウザ終了・PCスリープ中の待ち受けはできません。

OpenAI API方式で、会話・認識・音声・検索は従量課金です。検知した発話区間を認識APIへ送り、文字を会話として保存します。会話AIへの個人コンテキスト送信は従来どおり。録音ファイルやAPIキーを保存しません。ZIPに実際の会話・健康記録・調査結果は含めません。

GoogleマップはWindowsでは車の経路プレビュー。実際の運転ナビは対応スマホ側で開始してください。

## 検証

自動テスト101件。模擬音声とAI応答を使うChromiumテストでは、句読点をまたいだ一つの発話、会話を渡す操作、追加発言の保持、声かけ1回での休止、設定保存を確認済みです。Windows実機と実APIを使った会話の自然さは未検証です。

SHA-256は `SHA256SUMS` を参照してください。
