# ASTER（アスター）1.1

[Windows更新版をダウンロード](https://github.com/ej91tt0tt0/Codex/raw/refs/heads/main/downloads/aster-windows.zip)

生成り・墨色・細い罫線を基調とした新しい画面へ刷新し、音声・入力保持・写真・バックアップ・公開情報の調査を改善しました。

- **会話**：ただ聞く／一緒に考える／助言。口調・長さ・絵文字・質問頻度・気分・避けたい話題を調整。
- **記憶**：名前・呼び方・趣味・好物を任意で保存。内容を確認・修正・削除。好みの自動保存は任意・既定オフ。
- **会話の続きと遊び**：前回の続き、希望時の話題提案・振り返り・趣味の深掘り、AIとのしりとり・クイズ・なぞなぞ・物語。
- **音声と文字**：同じPCの履歴で切り替え。常時待ち受け、途中の追加発言、意味のまとまりでの交代を維持。
- **写真**：JPEG/PNG/WebPを長辺256〜1280pxを目安に整形・再エンコードして会話へ。画像ファイルは保存しません。
- **日記**：その日の本人の発言から下書き、本人が確認・修正して保存。編集・削除・書き出しも可能。
- **目標・通知**：自分で決めた目標の進捗管理。一度／毎日／毎週の通知を任意で登録。アプリ内表示と任意のブラウザ通知。
- **一時チャット**：その場の会話だけで、履歴・長期記憶・日記へ保存せず終了・再読み込みで破棄。
- **自律調査**：登録した目的の検索・出典確認・前回との差分を、指定間隔で実行。停止・上限・履歴付き。

自動の声かけは従来の控えめな設定を維持し、既定10分の沈黙後に1回だけ。返事がなければ休止します。登録テーマの自動提案は既定オフで、1時間ごとの情報収集は維持します。

## 更新

旧版を黒い画面でCtrl+Cで終了し、旧タブも閉じる → ZIPをすべて展開 → 中身を既存フォルダーへ上書き（**`.data` は残す**）→ `start_windows.bat` を起動。ZIP内フォルダー名 `yorisoi` は引き継ぎのため維持しています。旧版のダウンロード名も同じ最新版です。

Python 3.12以上、Chrome/Edgeを推奨。有効なOpenAI APIキーと利用枠が必要で、会話・認識・音声・画像・検索は従量課金です。キーの入力は非表示で保存しません。

## 自律動作の範囲

自律タスクは1・6・24時間間隔、最大10件。既定では自動実行を全体で1日3回まで、検索ツールを1回の調査で最大2回に制限します。会話・健康記録・記憶を渡さず、登録した調査内容と前回の結果だけを使います。上限は自律タスク専用で、通常会話・手動調査・従来のテーマ収集は別枠です。

広いWeb検索に接続できない場合は、公開ニュースRSSの見出し・配信要約と気象庁の予報を使って調べます。出典に取得方法と発表日時を表示します。記事本文や現在の鉄道・道路の実況を確認したものではありません。

任意のOS操作、コードの自己書き換え、購入、他人への連絡・投稿は実行しません。Googleマップの車経路連携は継続しますが、Windowsは経路プレビューで、運転ナビは対応スマホ側で開始します。

## 一時チャットと稼働条件

一時チャットもOpenAIへ送信され、サービス側のデータ保持は別です。アプリには会話・写真・設定を保存せず、Web検索や永続操作は使いません。画面メモリーに保持するのは直近200発言、モデルへ送るのは直近19発言です。

待ち受けとリマインダーにはブラウザとサーバーの稼働が必要です。PCスリープ・ブラウザ終了中の通知や音声認識、厳密な時刻どおりの配信は保証しません。自律調査はサーバー稼働中だけです。ログイン・端末間同期・終了中のプッシュ通知は未実装です。

詳しい使い方は同梱の `PC_START.txt` と `README.md`、検証範囲は `VALIDATION.md` を参照してください。ZIPにはAPIキーや実際の履歴・健康記録を含めません。SHA-256は `SHA256SUMS` を参照してください。
