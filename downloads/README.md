# よりそい — 常時待ち受け v0.9.0

[Windows更新版ZIP](https://github.com/ej91tt0tt0/Codex/raw/refs/heads/main/downloads/yorisoi-windows-handsfree.zip)

アプリを開いている間、声を検知すると会話できる常時待ち受けを追加しました。会話が途切れたり、メニューや別タブへ移動したりしても、待ち受けを停止しません。

## 最初の設定

1. 旧版を黒い画面でCtrl+Cを押して終了。
2. ZIPをすべて展開し、`yorisoi` の中身を既存の `yorisoi` へ上書き。既存の `.data` は残してください。
3. `start_windows.bat` を起動し、有効なOpenAI APIキーを入力。
4. ChromeまたはEdgeで「音声会話を開始」を押し、マイクを許可。
5. メニューの「アプリを開いている間、声を常時待ち受ける」「高精度な日本語認識」がオンなら準備完了。

高精度認識が有効で、ブラウザがマイクの許可を保存していれば、次回起動時から自動で待ち受けます。初回や自動開始できない環境ではボタン操作が必要です。今回から同じ起動アドレスを使う方式に変更したため、更新後の初回はマイクの再許可が必要な場合があります。ポート競合でアドレスが変わった場合も再許可してください。

## 使い方と停止

呼びかけ用の決まった言葉は不要です。そのまま話すと、発話区間を認識して会話に送ります。無言になっても待ち受けは続きます。AIが話している間も聞き取り、読み上げ中の節は句読点まで読んでから交代します。

上部のマイクボタンは、メニューや体調画面からも使えます。状態表示を確認し、必要なときに停止してください。

- 「マイクを止めて」または「待ち受けを止めて」：音声認識後、会話AIの返答を待たずに、このPCでマイクを停止。
- マイクボタン・停止ボタン：待ち受けと読み上げを停止。
- 停止後の再開：画面のマイクボタンか「音声会話を開始」を押す。
- 「設定変更、常時待ち受けを止めて」：常時待ち受け設定そのものをオフにして保存。

停止中は声での再開はできません。明示した停止は、同じタブを再読み込みしても維持します。設定のオン・オフはメニューからも変更可能です。自動の独り言・話題提案は会話画面を表示している間だけ行います。

対応ブラウザでは、同じよりそいを複数タブで開いても、1つのタブだけがマイクを使います。別の画面が使用中と出た場合は、その画面で停止してから開始してください。

## 動作する範囲

待ち受けには、PC・ブラウザの画面・よりそいのサーバー・インターネット・マイクが必要です。メニューや別タブに移動しても停止処理は行いませんが、ブラウザやOSが録音処理を休止する場合は継続できません。スリープ、ブラウザ終了、タブ休止、マイク切断中の待ち受けは保証しません。サーバーの黒い画面だけを残してブラウザを閉じた状態では使えません。

マイクが中断された場合は状態を表示し、画面へ戻ったときに再開を試みます。上部のマイクボタンを押す操作が必要な場合もあります。一時的な音声認識の接続失敗では、15秒待ってから新しく話した区間を受け付けます。エラー中の発言は保存して再送せず、もう一度話してもらう方式です。

## 音声・料金

待ち受け中の発話区間検知はPC内で行い、無音だけでは音声認識APIを呼び出しません。検知した音声区間はOpenAIへ送り、認識した文字は会話としてPC内に保存します。録音ファイルはアプリに保存しません。音声認識・AI会話・自然音声は従量課金です。

声紋で本人の声を識別する機能は含みません。周囲の人やテレビの声にも反応する可能性があるため、ヘッドセットを推奨します。マイク使用中は、アプリ上部とブラウザ側の表示で確認できます。

Python 3.12以上が必要です。ZIPにAPIキー・実際の会話や体調・調査結果は含めません。既存のデータと設定を引き継ぎ、新しい設定だけを追加します。

## 既存の機能と検証

青年らしい音声、サイバーパンクUI、音量に反応する円形表示、音声設定、改善リクエスト、Googleマップの車経路、AIのWeb検索・1時間ごとの情報調査を含みます。WindowsのGoogleマップは経路プレビューで、運転ナビは対応スマホ側で開始します。

自動テスト93件成功。Chromiumの実際のAudioWorkletと模擬マイクを使い、常時待ち受け、単一タブ占有、停止、自動再開、設定保持を確認しました。ブラウザ許可・非表示イベント・音声認識結果・AI応答は模擬しています。Windows実機のマイク・最小化・スリープ復帰、および実APIは未検証です。従来のダウンロード名も同じ最新版へ更新しています。
