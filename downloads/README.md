# よりそい — 句読点での交代・音声設定 v0.6.0

[Windows更新版ZIP](https://github.com/ej91tt0tt0/Codex/raw/refs/heads/main/downloads/yorisoi-windows-adaptive.zip)

## 読み上げの交代

AIが話している途中に話しかけても、その瞬間には止めず、読んでいる節を「、」「。」などの区切りまで読み切ってから交代します。その間も録音・認識を続け、追加や訂正を次の返答へ渡します。まだ読んでいない続きは再生しません。

「停止」ボタンと手動の「話す／割り込む」ボタンは、すぐ止めたい場合の操作として維持します。句読点のない文章は末尾まで読みます。自然音声は区切り単位で生成し、次の区切りだけ先読みします。短い区切りの間に待ち時間が入る場合があり、先読み済みの音声生成にもAPI料金が発生し得ます。

## 話題を固定しすぎない会話

直近の発言・話題転換を優先し、過去のテーマや登録キーワードに無理に戻さない指示を追加しました。反応のない質問や同じ提案を繰り返さず、毎回質問で終えなくてもよい方針にしています。追加の好みは下記の会話ルールでも設定できます。

## 音声で設定を改善する

音声会話中、次のように話してください。対応した設定はその場で保存し、次の返答から反映します。メニューにも同じ設定を表示します。

| 発言例 | 変更内容 |
| --- | --- |
| 設定変更、返答を短くして | 短めの返答 |
| 設定変更、返答を詳しくして | 詳しめの返答 |
| 設定変更、声をゆっくりにして | 速度1.0倍 |
| 設定変更、声を速くして | 速度1.25倍 |
| 設定変更、声を普通の速さにして | 速度1.12倍 |
| 設定変更、敬語にして | 敬語 |
| 設定変更、タメ口にして | タメ口 |
| 設定変更、声かけを止めて | 自動の独り言・提案をオフ |
| 設定変更、声かけを再開して | 自動の独り言・提案をオン |
| 設定変更、声かけを5分にして | 間隔変更（1・3・5・10分に対応） |
| 設定変更、会話ルール、質問を毎回付けないで | 会話上の追加ルールを保存（500文字まで） |
| 設定変更、会話ルールを消して | 追加ルールを削除 |

「設定変更」の明示的な接頭辞がある場合だけ永続設定として処理します。対応しない操作は案内を返し、コマンド実行・認証情報の変更・データ削除・公開は行いません。

## コード変更が必要な改善

「改善リクエスト、画面の文字をもっと大きくして」のように話すと、未実装の要望として保存します。メニューの「改善リクエスト」から確認・テキストへの書き出しができます。書き出した内容をこのチャットや開発者へ渡し、実装を依頼してください。

リクエストを保存しただけでは、ソースコードを変更したり、実装済みと表示したりしません。外部への自動送信も行いません。話し方の調整は設定で即時反映し、機能追加や不具合修正はこの開発フローで扱います。

## 更新・起動

1. 旧版を黒い画面でCtrl+Cを押して終了。
2. ZIPをすべて展開し、`yorisoi` の中身を既存の `yorisoi` へ上書き。既存の `.data` は削除しないでください。
3. `start_windows.bat` を開き、APIキーを入力してEnter。
4. ChromeまたはEdgeで音声会話を開始し、マイクを許可してください。

Python 3.12以上が必要です。会話・記憶・体調・設定は維持し、新しい設定項目と改善リクエストの保存先を追加します。声は青年らしい中低音の `ash`、初期速度は1.12倍。サイバーパンクUIと実測音量に反応する円形表示は維持しています。

## 料金・情報の扱い

会話・音声認識・自然音声の各OpenAI APIは従量課金です。高精度認識では音声を、自然音声では読み上げる文章をOpenAIへ送信します。録音はメモリー上だけで扱い、アプリは録音ファイルを保存しません。認識した文字と設定・改善リクエストはPCのSQLiteに保存します。AI会話には会話・記憶・最近の体調・地域・天気・ニュースと追加の会話ルールを送信します。

ZIPにAPIキー・実際の会話・体調記録・改善リクエストは含みません。地域の初期設定は愛知県碧南市浜田町、名鉄三河線などです。スピーカーの回り込みで誤検知する場合はヘッドセットを使ってください。旧ブラウザ認識方式では発声中の認識と音量表示は利用できません。人間の通話や医療の診断・緊急対応を行うアプリではありません。

## 検証

サーバー・音声設定22件、音声制御・録音処理32件、計54件の自動テストに成功。展開した配布ZIPで、句読点までの再生、追加発言、音声設定の保存、改善リクエストの書き出し、既存データ保持をChromiumで検証しました。ブラウザの発言・AI返答は模擬しています。話題転換は実APIでも確認。Windows実機のマイク・スピーカーでは未検証です。SHA-256は `SHA256SUMS` を参照してください。
