# よりそい — Windows音声対応版 v0.2.0

[音声対応版ZIPをダウンロード](https://github.com/ej91tt0tt0/Codex/raw/refs/heads/main/downloads/yorisoi-windows-voice.zip)

## 初回起動

1. [Python 3.12以上](https://www.python.org/downloads/windows/)をインストールします。「Add python.exe to PATH」を有効にしてください。
2. ZIPを右クリックして「すべて展開」します。
3. `yorisoi` フォルダーの `start_windows.bat` を開き、APIキーを入力してEnterを押します。キーは非表示で、ファイルには保存しません。空欄なら記録モードです。
4. WindowsのChromeまたはEdgeで開き、「音声会話を開始」を押してマイクを許可します。話し終えると自動送信し、AIの返答を読み上げます。
5. 「停止」でマイク・読み上げを停止します。終了時は黒い画面でCtrl+Cを押してください。

起動時に時刻に合わせて挨拶します。ブラウザが自動再生を制限した場合は「音声会話を開始」または「挨拶を聞く」を押してください。返答の読み上げ中は聞き取りを停止し、読み上げ後に再開します。別のタブに移動した場合もマイクを停止します。

## 旧版から更新

旧版の黒い画面でCtrl+Cを押して終了し、展開した `yorisoi` の中身を、従来の `yorisoi` フォルダーへ上書きしてください。既存の `.data` フォルダーは削除しないでください。会話・体調・記憶を引き継げます。再度 `start_windows.bat` を開いてください。

## マイクが動かないとき

Windowsとブラウザのマイク権限、インターネット接続を確認してください。既定ブラウザが非対応の場合は、黒い画面の `READY` の右のアドレスをChromeまたはEdgeで開きます。文字入力も利用できます。

## 情報の取り扱い・検証

音声認識にブラウザのサービスを利用し、音声がブラウザの提供元へ送信される場合があります。アプリは録音ファイルを保存しません。認識した文字は会話として保存され、AI利用時は会話・記憶・最近の体調・地域・天気・ニュースをOpenAIへ送信します。OpenAI APIは従量課金です。

ZIPにAPIキー・会話履歴・体調記録は含めません。対象地域の初期設定（愛知県碧南市浜田町、名鉄三河線など）は含みます。クラウドのネットワークシークレットはPCに引き継がれません。PC内だけで動作し、公開サーバーは作りません。診断・緊急対応用の医療アプリではありません。

サーバーの既存テスト9件、音声制御テスト9件、Chromiumでの模擬音声による画面操作を確認済みです。Windows実機の音声入出力は未検証です。ZIPのSHA-256は `SHA256SUMS` を参照してください。
