# よりそい — Googleマップ車ナビ連携 v0.7.0

[Windows更新版ZIP](https://github.com/ej91tt0tt0/Codex/raw/refs/heads/main/downloads/yorisoi-windows-maps.zip)

**Windowsでは車の経路プレビューを開きます。実際の運転中の音声ナビは、対応するスマホのGoogleマップで使用してください。** よりそいがGoogleマップの画面を読み取ったり、実際のナビ開始を確認したりする機能ではありません。

## 音声で使う

- 「車で名古屋駅までナビして」
- 「車で碧南駅から名古屋駅までナビして」
- 「Googleマップで名古屋駅までナビして」
- 「Googleマップを開いて」

「車のナビを開いて」のように目的地がなければ聞き返します。次に「目的地は名古屋駅」と答えてください。聞き返しは5分以内の次の発言にだけ有効で、別の話題に移ると破棄します。

通常の `start_windows.bat` 起動では、このPCの標準ブラウザへGoogleマップを開く操作を送ります。自動で開かなければ、会話画面に表示される「Googleマップで車ナビを開く」を押してください。Google側の目的地や候補地点を確認して使ってください。

## 画面から使う・スマホへ渡す

メニュー → ナビ・調べものから、出発地と目的地を入力して開くこともできます。出発地を空欄または「現在地」にすると、Googleマップへ出発地を指定せず渡します。よりそい自身はGPSを取得しません。

「スマホ用リンクをコピー」で同じ車経路のURLをコピーし、ご自身のスマホで開けます。Googleマップが利用可能で現在地を使える場合などにナビへ進みます。出発地が現在地から離れている、位置情報が使えない、端末がナビ非対応といった場合は経路プレビューになります。必要なナビ開始操作はGoogleマップ側で行ってください。

## できる範囲

外部連携は今回、Googleマップだけに対応しました。Google公式のMaps URLに、目的地・出発地・車モード・ナビ要求を渡します。Google APIキーは不要です。任意のアプリを無制限に操作したり、OSコマンドをAIに実行させたりする仕組みではありません。他のアプリは個別の連携を追加する必要があります。

開く操作は、利用者の明示的な音声依頼かナビ画面の操作からのみ実行します。AIの文章やニュース記事に命令が含まれていても起動しません。履歴の表示やアプリの再起動だけでも再実行しません。`server.py` 直接起動や `--no-browser` では自動起動はオフで、リンクボタンを使います。

## 更新

1. 旧版を黒い画面でCtrl+Cを押して終了。
2. ZIPをすべて展開し、`yorisoi` の中身を既存の `yorisoi` へ上書き。既存の `.data` は削除しないでください。
3. `start_windows.bat` を開き、APIキーを入力してEnter。
4. ChromeまたはEdgeで音声会話を開始し、「車で名古屋駅までナビして」と話してください。

Python 3.12以上が必要です。車経路の作成自体はOpenAI APIキーがなくても、メニューの入力欄から使えます。会話・記憶・体調・設定は維持し、連携履歴の保存先を追加します。

## これまでの機能

青年らしい中低音、サイバーパンクUI、実測音量に反応する円形表示、句読点まで読んで交代する方式、追加発言の保持は維持しています。音声で「設定変更、返答を短くして」「設定変更、声かけを止めて」「設定変更、会話ルール、質問を毎回付けないで」と設定できます。「改善リクエスト、内容」は未実装の要望として保存・書き出しできます。

## 情報の扱い・料金

Googleマップを開くと、目的地・指定した出発地はGoogleへ送られます。現在地の権限はGoogleマップ側で確認してください。連携履歴と発言はPCのSQLiteに保存され、データ管理から他の記録と一緒に削除できます。「スマホ用リンクをコピー」はコピーだけで、他の人やサービスへ自動送信しません。

OpenAIの会話・音声認識・自然音声は従量課金です。高精度認識では音声を、自然音声では読み上げる文章を送ります。録音ファイルはアプリに保存せず、認識した文字を保存します。AI会話には会話・記憶・最近の体調・地域・天気・ニュース・会話ルールを送ります。句読点単位の自然音声生成と先読みには料金が発生し得ます。

ZIPにAPIキー・実際の会話履歴・体調・改善リクエスト・連携履歴は含めません。地域の初期設定は愛知県碧南市浜田町、名鉄三河線などです。実ユーザーの現在地としては扱いません。
